# ✊✋✌️ Kéo Búa Bao

> 🎮 Game Kéo Búa Bao chạy trực tiếp trên trình duyệt – đơn giản, vui nhộn và mang tính may rủi.

🌐 **Live Demo:** https://panbap.github.io/keobuabao/

---

## 🚀 Giới thiệu

Đây là một project **Kéo Búa Bao ** được xây dựng bằng HTML, CSS và JavaScript.

Người chơi sẽ chọn Kéo, Búa hoặc Bao để đấu với máy. Kết quả được quyết định theo luật quen thuộc:

- ✊ Búa thắng Kéo  
- ✌️ Kéo thắng Bao  
- ✋ Bao thắng Búa  

---

## 🎮 Gameplay

- Chọn Kéo ✌️, Búa ✊ hoặc Bao ✋  
- Máy sẽ chọn ngẫu nhiên  
- So sánh kết quả thắng / thua / hòa  
- Hiển thị kết quả ngay lập tức  

---

## ✨ Tính năng

- 🎮 Gameplay đơn giản, dễ chơi
