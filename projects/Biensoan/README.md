# 🧑‍💻 Online Code Editor

> ⚡ Trình biên soạn HTML, CSS, JavaScript chạy trực tiếp trên trình duyệt.

🌐 **Live Demo:** https://panbap.github.io/Biensoan/

---

## 🚀 Giới thiệu

Đây là một project **Online Code Editor** giúp bạn viết và chạy code ngay trên trình duyệt mà không cần cài đặt môi trường.

Phù hợp để:
- 🧑‍💻 Test nhanh HTML/CSS/JS  
- 📚 Học lập trình front-end  
- ⚡ Demo code nhanh chóng  

---

## ✨ Tính năng

- 📝 Viết code HTML, CSS, JavaScript  
- ▶️ Chạy code trực tiếp (real-time)  
- 📂 Chọn thư mục & lưu file  
- ⚡ Giao diện đơn giản, dễ dùng  
- 🌐 Không cần cài đặt  

---

## 🛠️ Công nghệ sử dụng

- HTML5  
- CSS3  
- JavaScript

## ⚙️ Cách sử dụng

### 1. Clone repo

```bash
git clone https://github.com/your-username/biensoan.git
cd biensoan
```

### 2. Chạy project

Mở file:

```bash
index.html
```

hoặc truy cập trực tiếp:

👉 https://panbap.github.io/Biensoan/
